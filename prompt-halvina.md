## Aturan pencatatan

- Setiap ada prompt baru, tambahkan satu baris di bawah tabel ini.
- Format timestamp: `YYYY-MM-DD HH:MM WIB`.
- Kolom **Prompt** ditulis verbatim (apa adanya).
- Kolom **Item/Modul** diisi jika prompt terkait pengerjaan SIMSHIP; kosongkan jika tidak.
- Pencatatan hanya berjalan pada agent/sesi yang membaca file ini. Jika prompt diberikan di sesi atau agent lain, agent itu perlu menambahkan entrinya sendiri.

## Hasil pengecekan prasyarat (dari prompt #3)

- **MySQL sesuai `.env`:** host `127.0.0.1:3306`, user `root`, tanpa password — **terhubung**, tetapi database `simship` **tidak ada**. Daftar database: `information_schema`, `it-asset`, `it-inventory`, `mysql`, `performance_schema`, `sys`. Jadi tabel `migrations` MySQL tidak bisa diperiksa.
- **SQLite lokal:** `database/database.sqlite` (106.496 byte) berisi tabel `migrations` dengan 4 baris, termasuk `2026_11_15_113355_add_role_and_status_to_users_table` (id 4, batch 1). Tabel `users` di file ini sudah punya `username`, `role`, `is_active`, tetapi **belum** `last_login_at`.
- **`phpunit.xml`:** `APP_ENV=testing`, `DB_CONNECTION=sqlite`, `DB_DATABASE=:memory:`, `DB_URL=`; `CACHE_STORE=array`, `SESSION_DRIVER=array`, `QUEUE_CONNECTION=sync`. Tidak ada env `DB_*` yang terekspor di shell, sehingga tidak ada yang menimpa pengaturan ini. Tes terisolasi dari DB dev.
- **`migrate` tidak dijalankan.** Akses DB hanya berupa query `SELECT`/`SHOW` melalui PDO.
